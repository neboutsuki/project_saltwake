# SALTWAKE art

All game art lives in this folder as ordinary image files. Code refers to art **only by alias** (for example
`ui/heart` or `weathered/media_0396`); `manifest.json` maps each alias to a file. `python build.py` embeds every file
into the single playable HTML.

## Replacing or adding art
1. Open the file in any image editor (PNG/WebP for sprites, SVG for UI icons) and paint over it. Keep the same pixel
   size and transparent background so draw sizes and anchors stay correct.
2. If the file is generated by `tools/bake_art.py`, add its path (relative to `assets/`) to `BAKE_SKIP` in that script
   so a re-bake never overwrites your painting.
3. Run `python build.py`. Nothing else needs to change.

To add a new piece, put the file here, add a manifest entry `{"path": "assets/<file>", "mime": "...", "aliases":
["<alias>"], "pack": "<your-pack>"}`, and reference the alias from code.

## Folders
| Folder | Contents | Made by |
|---|---|---|
| `media_*.png/webp` | Original game art: buildings, characters, creatures, props, foliage, terrain, icons (622 files) | Recovered original art, with `tools/remaster_assets.py` grading (originals kept in `original/`) |
| `weathered/` | Weathered variant of every building sprite (light, footing grime, brine, salt streaks, roof ash) | `tools/bake_art.py` (pack `art-v031`) |
| `decals/` | Terrain decals: salt crusts, ash drifts, cracks, pebbles, puddles | `tools/bake_art.py` |
| `fx/` | Particles: ash flakes, ember, rain streak, splash | `tools/bake_art.py` |
| `ui/` | HUD icons and weapon silhouettes (SVG) | `tools/bake_art.py` |

## What is still drawn by code
Rendering effects such as lighting, bloom, color grade, fog, shadows cast from sprites, wind sway, damage arcs and
attack telegraphs are runtime effects, not art, and stay in code.

These older harbor pieces are still drawn with shape primitives inside the harbor renderer
(`HARBOR_DOCUMENT` in `source/game.template.html`). They should be replaced with sprites in a future art pass:

| Piece | Function | Notes |
|---|---|---|
| Plaza lantern pillars | `plazaPillar` | 17 primitives |
| District signs, hearths and market details | `districtProp` | 25 primitives |
| Storm walls, gates, sea wall | `stormWall`, `drawGates`, `drawSeawall` | walls and gates |
| Watch towers | `watchTower` | |
| Moored boats | `drawBoat` | |
| Yard fences and details | `yard` (partly sprites already) | |

The field (raid) maps are already fully image-based, apart from map markers (exit rings, track markers), which are UI.
